# ComponentMatch Agent 技术二面演示指南

## 演示前准备

全部供应商、库存、报价、资质与历史表现都是 DEMO 模拟数据，不是实时市场报价。
ISO9001 模拟核验不等于原厂授权、产品真伪验证或真实企业资质。

首次使用先完成 [README](../README.md) 的安装、配置与灌数步骤。演示时在项目根目录打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_demo.ps1 -ApiPort 8001 -UiPort 8502
```

打开 <http://127.0.0.1:8502>，后端文档为 <http://127.0.0.1:8001/docs>。
这里使用可替换的示例端口；如被占用，应另选空闲端口，不结束无关服务。
无需激活虚拟环境。脚本不覆盖 `.env`、重置数据或调用模型，Ctrl+C 停止本次服务。
分别启动与执行策略限制的替代命令见 README。

演示前查看启动器的报价时效统计。旧快照或报价过期时可能没有推荐，应按 [数据说明](../data/README.md) 显式创建新库并修改 DATABASE_URL；不要回拨时间或悄悄改时间戳。实际匹配仍以本次 Agent 响应为准。

**费用边界：** 页面提交会调用真实配置的 DeepSeek，并可能产生服务商费用；
选择案例、查看证据、清空需求和检查后端连接不会调用模型。真实演示需明确同意该次调用。
本轮自动验收没有新增付费调用；Mock 验证不代表今日真实模型成功。

## 约七分钟操作路线

| 时间 | 页面操作 | 讲解重点 |
|---|---|---|
| 0:00–0:40 | 打开首页，指出 DEMO 标识和自然语言采购入口 | 解决精确料号采购中人工核对库存、交期、预算、资质和历史表现的成本；输出候选，不自动下单 |
| 0:40–2:00 | 选“正常匹配”，在已获调用授权后提交；核对需求及原文依据 | DeepSeek 提取条件；用户必须核对。单价与总预算是独立硬条件，后端默认不冒充用户要求 |
| 2:00–3:15 | 看卡片、五维图、证据，并展开实际 Agent 工作流 | Python 决定分数、排名和风险；模型只选择合法证据解释。LangGraph 用显式状态和条件边处理澄清、无匹配与错误，不需要多 Agent |
| 3:15–4:30 | 分别选择“成本优先”“质量优先”案例并提交，核对解析偏好与本次权重 | 均通过Agent API；偏好改变后端预定义权重，模型和前端不改评分公式 |
| 4:30–5:45 | 选“信息缺失”，提交后补充文字，或显式确认数量和交期字段 | 保留原文和草稿；补充文本或确认所选字段后发起新请求，不自动确认。缺少条件时不生成推荐，不擅自补全数量或交期 |
| 5:45–6:30 | 选择“约束过严”案例并提交，查看无匹配结果 | 无匹配不放宽要求；查看实际检索/排除数和中文失败原因，一条报价可能触发多个原因 |
| 6:30–7:00 | 总结数据来源和边界 | 全部业务数据模拟；不承诺实时库存、锁价或采购结果；异常处理已做离线验证 |

选择案例只填入文本并清除旧结果，不自动提交。页面不会加载历史验收结果冒充动态推荐。
页面没有模型开关或结构化采购表单；所有业务提交通过Agent API，现场调用需事先获得授权。
AI 原文有冲突或不支持条件时应直接修订，不能自动确认，也不能把原厂授权改成 ISO9001。

## 评分与证据怎么讲

固定锚点归一化，所有分项截断在0～100分；权重来自后端响应。
默认档位为价格20%、交期25%、质量30%、准时交付20%、响应5%。其他档位以页面本次权重为准。

| 维度 | 当前后端口径 |
|---|---|
| 价格 | 有效模拟参考价为锚点；报价为参考价一半时满分，达到1.5倍时为0；参考价失效则保守记0 |
| 交期 | 0自然日对应100分，30自然日对应0分；先满足用户交期硬上限 |
| 质量 | 最近六个完整自然月合格片数/检验片数；95%对应0分，100%对应100分 |
| 准时交付 | 同期准时交付订单/到期订单；80%对应0分，100%对应100分 |
| 响应 | 平均响应小时数；1小时及以内满分，48小时及以上为0 |

后端将各分项加权贡献求和，Decimal 保留六位精度；缺历史不重分配权重，小样本按原规则封顶50分。
同一供应商仅保留最佳报价，固定同分排序，最多三家。详见 `scoring_design.md`，本轮未改动这些规则。

卡片突出排名、总分、单价、货款总额、交期与库存；详细理由、得分、贡献、历史和资质在展开区。
百分比是原始指标，得分是0～100的评分，不能混淆。展示层只将人民币分换成元、比例换成百分比。
原始代码和完整响应在可选“技术详情”，正常业务表格为中文。

## 异常、轨迹与项目限制

- 模型解析超时/认证失败：显示错误，不假装成功；检查后端配置或稍后手动重试，不自动切换其他匹配入口。
- 模型解释失败：保留原分数与排名，明确显示“证据模板”，不是模型解释成功。
- 数据过期、库存不足、资质缺失、预算超限：按实际规则排除，不修改数据或时钟掩盖。
- 不要破坏密钥或付费制造故障；超时及降级已在离线测试覆盖。
- AI 轨迹来自后端节点记录，显示职责、真实耗时及返回时的工作流状态；不足1毫秒显示“<1 毫秒”。
  这不是实时进度；无轨迹时只显示标注为静态的流程说明，不伪造记录。
- 本轮浏览器 AI 响应有“离线 Mock”提示。历史真实 DeepSeek 验收见 [归档记录](history/deepseek_live_verification.md)。
- 自然语言完整性检查有范围，不能保证任意表达无遗漏；须人工核对结构化条件。
- 不支持替代料兼容性、拆单、锁价、库存预留、支付、供应商入驻，未接入真实企业 ERP。
- 本机 Demo 没有生产认证、并发限流和长期审计；会话提交保护不是跨会话幂等。
- 同步数据库线程不能严格中断；前端超时只停止等待，不保证取消后端工作。

当前测试与边界见 [验证索引](verification.md)；历次报告保留在 [历史目录](history/README.md)。无需 PPT，围绕实际输入、返回值和证据讲解。
